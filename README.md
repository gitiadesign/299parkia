# 299 Park Avenue: Everything but the Work

Complete standalone export of the elevation opening working fork.
Based on the November 19, 2026 export from source commit 6a11a488da14dddb67310c14e00b632f76fa4d53.

## Run locally

1. Extract the entire ZIP.
2. Open the 299_Park_Avenue folder and double-click index.html. Keep the assets and other files beside it.
3. Read the dossier screen, then use its down arrow below the text to enter.

No server, Terminal, or internet connection is needed. The original Python preview server is still available as an optional alternative.

## Host and share

Upload this folder's contents to any static web host. The root index.html must remain beside the JavaScript, CSS, and assets folder. Site access permissions are not included in this export; configure those with your chosen hosting service.
